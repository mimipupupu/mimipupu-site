# Mimipupu — portfolio & commissions site

- `public/` is the live website (Netlify publishes this folder).
- `public/content/*.json` holds everything you edit from the admin page (prices, queue, prints, payment details…).
- `public/admin/` is the private admin page: https://mimipupu.netlify.app/admin
- `dev/` holds the source used to rebuild the page; you don't need to touch it.
